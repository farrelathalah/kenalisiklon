# Kenali Siklon, Waspadai Banjir

Infografis digital interaktif berbasis web tentang siklon tropis, hujan lebat, dan risiko banjir di Indonesia. Dibaca dengan menggulir sebagai satu perjalanan zoom: Bumi, badai dari satelit, mata badai, kota diguyur hujan, di dalam rumah, dan peta jejak siklon di layar TV.

Disusun oleh PT AeroResilience Indonesia (Kelompok 4) untuk Kelompok 3, WI2022 Manajemen Proyek, Program Studi Meteorologi ITB, Semester I 2026/2027.

Seluruh web ada di satu file, `index.html` (HTML, CSS, dan JavaScript, dengan gambar tertanam). Tidak perlu proses build. Produk ini bersifat edukatif dan bukan pengganti informasi resmi BMKG, BNPB, atau BPBD.
